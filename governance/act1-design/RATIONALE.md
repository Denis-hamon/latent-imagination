# Act I design rationale (adversarial-ready)

Every parameter above is chosen against the published critiques, not for convenience:

- **scaffold pinned**: heterogeneous scaffolds poison cross-family comparison (review F-C1/EC-31); ours is ours, recorded by git sha.
- **stop-at-first-valid**: matches the ERBVE denominator contract in the Glossary; any other rule and the metric is a different one.
- **max_attempts=25**: bounded cost; beyond 25 the point is made (the task isn't getting valid this run — but we COUNT them, don't truncate the metric).
- **macro primary**: micro lets a handful of noisy tasks dominate the claim line; macro treats each task as a citizen. Pooled is printed, never hidden.
- **tolerance ±2pp inclusive**: provisional arithmetic home for the reproducibility claim; flagged OQ-5; confirm BEFORE the field runs.
- **quarantine cap 10%**: the frozen tree's fixed value; above it, validity of the instrument itself is the story.
- **Anchoring**: this story proves the PRECEDENCE mechanics on a fixture ledger. The live OTS anchor happens in the same ceremony immediately before the campaign (2.7); the design.toml hash at that moment is the one the preprint cites.
