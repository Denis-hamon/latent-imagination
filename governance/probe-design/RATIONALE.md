# Probe rationale (adversarial-ready)

- **One data basis for all arms:** varying data basis per arm is the exact
  failure UJ-2 exists to audit (sandbagging). FR-11 forbids it; we register once.
- **The bar is economic, not statistical.** registered_bar = 88.89% comes from
  measured Epic-2 costs (exec $0.0025 / regen $0.0200). If costs move, the bar
  moves BY AMENDMENT, not by edit.
- **Precision at a recall floor:** raw precision games abstention; the floor
  rule keeps the arm honest — reported at the lowest recall ANY arm reaches.
- **Two CIs, one method each, named.** Wilson for the proportion, percentile
  bootstrap for the delta. Anything else would be invented after seeing data.
- **Branch (ii) is a positive publishable outcome** — the null is not a failure,
  it is the arbitration working. We pre-registered the document templates.
